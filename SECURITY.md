# Security

Strom Widget reads only files that Strom Research writes on the same Mac and does not use the network.

## Reporting a vulnerability

Security issues are reported privately through GitHub:
[Report a vulnerability](https://github.com/ACiDekCZ/strom-mac/security/advisories/new)
(*Security → Report a vulnerability*), not in a public issue.

A report helps most with the version (the release name, or *Get Info* on Strom Widget.app), the macOS version and
the steps that show the problem. Only the latest release gets fixes.
