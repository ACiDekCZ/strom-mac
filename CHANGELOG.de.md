# Was ist neu im Strom Widget

[English](CHANGELOG.md) · [Čeština](CHANGELOG.cs.md) · Deutsch

Die Änderungen jeder Version in Kürze. Die Downloads stehen bei
[GitHub Releases](https://github.com/ACiDekCZ/strom-mac/releases).

## 0.1.1

- **Links öffnen sich in der installierten Strom-App.** Ein Klick auf das Widget, eine Zeile oder einen Link in der
  App Strom Widget öffnet die aus Chrome oder einem anderen Chromium-Browser installierte Strom-App (Strom Beta für
  Beta-Adressen); ohne sie einen Tab dieses Browsers oder von Chrome, und erst dann den Standardbrowser.
- **Das Widget hält mit der Forschung Schritt.** Pause, Uhrzeit, Linien, „Wartet“ und Funde erscheinen in etwa einer
  Minute, und eine Pause, deren Zeit vorbei ist, wird nicht mehr angezeigt.

## 0.1.0

*Die erste Version. Benötigt macOS 14 oder neuer und Strom Ahnenforschung 1.21 oder neuer auf demselben Mac.*

- **Strom Ahnenforschung auf dem Mac-Schreibtisch.** Ein Widget in vier Größen (klein bis extra groß) zeigt, woran die
  Forschung gerade arbeitet, was sie in den letzten 24 Stunden gefunden hat (Personen, Familien, Quellen, gelöste
  Widersprüche) und was auf eine Entscheidung wartet. Eine Forschung pro Widget; bei mehreren wählt jedes Widget seine.
- **Namen lassen sich ausblenden.** Das Widget zeigt die Übersicht auf Wunsch ohne Namen von Personen, für einen
  Schreibtisch, den auch andere sehen.
- **Ein Klick öffnet die Strom-App** an der passenden Stelle.
- **Die App Strom Widget** listet die Forschungen auf diesem Mac, zeigt, wie das Widget hinzugefügt wird, stellt die
  Sprache ein (Tschechisch, Englisch, Deutsch; standardmäßig die Sprache der Forschung) und deinstalliert alles mit
  einer Schaltfläche.
- **Die Daten bleiben auf dem Mac.** Das Widget liest nur die Dateien, die die Forschung auf demselben Mac schreibt;
  nichts geht über das Netz.
